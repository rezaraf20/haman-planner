# Roadmap

**Author:** Reza Rafiei

## Phase 0 — Foundation — implemented
- Product specification
- Domain model
- Database contract
- API contract
- Security and contribution policy

## Phase 1 — MVP — implemented
- PostgreSQL repository
- Goals/projects/milestones/tasks
- Hierarchical weighted progress
- Dependencies
- Priority and capacity planning
- Daily planning
- Scheduling
- Execution logs
- Failure reasons
- Reminders
- Telegram text commands
- Telegram voice input

## Phase 2 — Voice — implemented
- Speech-to-text
- Intent parser
- Entity resolution
- Ambiguity clarification
- Confirmation flow
- Voice-compatible reviews

## Phase 3 — Intelligence — implemented
- Priority engine
- Goal health
- Analytics
- Deterministic reviews/actions
- Grounded planner queries
- AI intent parsing with confirmation boundaries
- Grounded AI planner recommendations

## Phase 4 — Release hardening — implemented
- API authentication and rate limits
- Request IDs and idempotency protection
- PostgreSQL CI and migrations
- Unit and feature tests
- OpenAPI/API documentation
- Backup/restore runbook
- Observability runbook
- Production checklist
- Health/readiness endpoints
- Reminder retry/backoff
- Queue worker and scheduler containers

## Phase 5 — Personal Haman Planner Platform — implemented
- Browser dashboard
- Today/tasks/goals/projects/analytics/reviews views
- Task filtering and search API
- Notes and decisions APIs
- Planner recommendations endpoint
- Production queue/scheduler topology
- Explicit AI provider selection for OpenAI, Gemini, Groq, OpenRouter and xAI-compatible endpoints
- Progress recalculation after task/milestone/project moves and deletes

## Phase 6 — Commercial SaaS — future
- Multi-user authentication and workspace membership
- Roles and permissions
- Billing/subscriptions and usage limits
- Tenant isolation
- Public API keys and webhooks
- Google Calendar / Notion / GitHub / Slack integrations
- Advanced PWA/mobile experience
- Team analytics
- Enterprise SSO

The product remains proprietary to Reza Rafiei throughout all phases.
