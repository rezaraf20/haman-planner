# Review Engine

**Author:** Reza Rafiei

## Daily review
Capture completed work, unfinished work, blockers, actual time, energy/focus and the next day's highest-value actions.

## Weekly review
Summarize goal/project progress, planned vs actual time, failures, repeated blockers, capacity, overdue work and next-week commitments.

## Monthly review
Analyze strategic progress, recurring execution problems, estimation accuracy and goal health.

Reviews should produce decisions and actions, not only summaries.
