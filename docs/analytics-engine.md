# Analytics Engine

**Author:** Reza Rafiei

## Core metrics
- Completion rate
- Planned vs actual minutes
- Estimation error
- Schedule variance
- Deep-work minutes
- Focus/energy trends
- Overload rate
- Deferred-task rate
- Failure rate
- Preventable failure rate
- Blocked/waiting time
- Goal progress
- Goal velocity
- Goal health

## Goal velocity
Compare actual progress achieved during a period with the remaining progress and available time required to reach the target date.

The system should distinguish:
- current status
- historical trend
- forecast inputs

It must not manufacture a forecast when data is insufficient.

## Failure analysis
Group failures by structured reason and compare frequency, severity and preventability. The purpose is to identify process improvements.

## Reporting
Daily: execution and blockers.
Weekly: goals, projects, planned vs actual, failures, capacity and next actions.
Monthly: trends, strategic progress and recurring system problems.

All metrics must be reproducible from stored records.
