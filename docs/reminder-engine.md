# Reminder Engine

**Author:** Reza Rafiei

Reminder types:
- deadline
- scheduled start
- overdue
- follow-up
- recurring
- review
- inactivity

Rules:
- Do not spam.
- Respect user quiet hours.
- Suppress reminders for completed/cancelled items.
- Escalate only when the underlying item remains relevant.
- Record delivery status and failures.
- Reminder generation must be deterministic from planner state plus explicit settings.
