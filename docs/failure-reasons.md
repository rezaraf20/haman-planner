# Failure Reasons

**Author:** Reza Rafiei

Initial controlled vocabulary:
- NO_TIME
- POOR_ESTIMATION
- UNEXPECTED_WORK
- LOW_ENERGY
- DISTRACTION
- TOO_DIFFICULT
- UNCLEAR_TASK
- WAITING
- BLOCKED
- WRONG_PRIORITY
- CONTEXT_SWITCHING
- PERSONAL_ISSUE
- TECHNICAL_PROBLEM
- OTHER

Each failure records preventability (yes/no/partial), severity and notes. The vocabulary can evolve through reviews, but historical records retain their original reason.
